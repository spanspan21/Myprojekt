### Lessons Learned
- **API-Error-Ursache**: zu große Einzel-Nachrichten (riesiger Write-Call + lange Analyse in einem) → Output-Limit. Fix: eine Datei pro Nachricht, kompakte Schritte.
- Kotlin: `@Synchronized` ist reentrant; `key()` in Compose erzwingt keine Uniqueness (nur LazyColumn); `animateRectAsState` existiert (Rect.VectorConverter)
- Build: `export JAVA_HOME="C:/Program Files/Android/Android Studio/jbr" && cd "C:\Users\ms\Documents\Myprojekt" && ./gradlew assembleDebug` / `testDebugUnitTest`
- Handy: `adb devices` → bei "unauthorized" USB-Debugging-Dialog am Gerät bestätigen; dann `adb install -r app/build/outputs/apk/debug/app-debug.apk`
