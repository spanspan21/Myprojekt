## 3. Bewusst NICHT gebaut (mit Grund)

Kein „unfertig", sondern absichtliche Stopps — sie würden bewusste, teils per Test gesperrte Design-Entscheidungen umkehren:

- **ACWR skaliert den Plan nicht automatisch.** Nur der opt-in Vorschlag. Der Auto-Eingriff ist per `AuditFixesTest` bewusst gesperrt („Disziplin über Komfort"). → stattdessen: Load-Spike feeds den vorhandenen Vorschlag.
- **SkillGraph steuert nicht die Engine-`level`-Nahtstelle aller Disziplinen.** Das würde getestetes Plan-Generierungs-Verhalten für alle Nutzer ändern (Regressionsrisiko). → stattdessen: die *Anzeige* (Strength-Karte).
- **Inhärent laufend:** Density wirkt heute nur auf token-basierte UI (Adoption wächst); ein Beauty-Pass *jedes* Screens ist naturgemäß nie „endgültig fertig".
